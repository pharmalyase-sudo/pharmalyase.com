- Direct email CTAs to pharmalyase@gmail.com
- LinkedIn link to the Pharmalyase profile

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `pharmalyase-website`.
2. Upload `index.html`, `styles.css`, `script.js` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` and save.
6. GitHub will provide the public website URL.

## Important before launch
- Add the final company logo when available.
- Add a dedicated business phone/WhatsApp only if you want it public.
- Replace placeholder service claims with the exact services you are ready to deliver.
- Add legal pages (Privacy Policy / Terms) before collecting visitor information.
- If you add forms, use a proper form backend instead of exposing credentials in frontend code.
